# 📘 Enterprise Learning Management System (LMS) - Backend API

A robust, secure, and highly scalable Learning Management System (LMS) backend built with **Spring Boot 3** and **PostgreSQL**. This system is designed to seamlessly manage the educational process between Instructors and Students, featuring automated grading, OTP-based attendance, advanced reporting, and enterprise-grade security.

## 🚀 Key Features

### 🛡️ Security & Architecture
*   **Stateless Authentication:** Secured using **JWT (JSON Web Tokens)**.
*   **Role-Based Access Control (RBAC):** Strict permissions mapping for `Student` and `Instructor` roles.
*   **Context-Aware Authorization:** Uses `SecurityContextHolder` to securely identify users, completely mitigating **IDOR** (Insecure Direct Object Reference) vulnerabilities.
*   **Optimized Data Transfer:** Implements the **DTO (Data Transfer Object)** pattern to prevent over-fetching and sensitive data exposure.

### 👨‍🏫 Instructor Module
*   **Course & Lesson Management:** Create courses, manage durations, and add media files.
*   **Question Banks & Quizzes:** Build question banks and generate randomized quizzes for students.
*   **Assignment Management:** Create assignments, track student submissions, and grade them manually.
*   **Advanced Analytics:** Generate Excel (`.xlsx`) performance reports and visual charts (`.png`) for course statistics.

### 👨‍🎓 Student Module
*   **Enrollment:** Securely browse and enroll in available courses.
*   **OTP Attendance:** Mark lesson attendance using a secure, time-sensitive OTP generated by the instructor.
*   **Assessments:** Submit assignment PDFs and take randomized quizzes with **auto-grading** support.
*   **Progress Tracking:** View grades and personal performance.

### 🔔 Notification System
*   **In-App Alerts:** Real-time database-driven notifications for grading, enrollments, and quiz creations.
*   **Email Integration:** Automated email notifications sent via **JavaMailSender**.

## 🛠️ Tech Stack

*   **Core:** Java 17+, Spring Boot 3
*   **Security:** Spring Security, JJWT (Auth & Authorization)
*   **Database:** PostgreSQL, Spring Data JPA / Hibernate
*   **Utilities:** Lombok (Boilerplate reduction)
*   **Reporting & Media:** 
    *   `Apache POI` (Excel Report Generation)
    *   `JFreeChart` (Performance Data Visualization)
    *   `MultipartFile` (Media/File Uploads)

## 🔌 API Endpoints Summary

> **Note:** All endpoints (except `/auth/**`) require a valid JWT token in the `Authorization: Bearer <token>` header. The system automatically extracts user identity and roles from the token.

*   **Auth:** `/auth/register`, `/auth/login`
*   **Courses:** `/course/allCourses`, `/course/uploadMedia`
*   **Instructors:** `/instructor/create-course`, `/instructor/create-quiz`, `/instructor/correct-assignment`
*   **Students:** `/students/add-course`, `/students/attend-lesson/{lessonId}`, `/students/take-quiz`
*   **Notifications:** `/notification/unread`, `/notification/markAsRead/{id}`
*   **Reports:** `/report/{courseId}/excel`, `/report/{courseId}/chart`


## 🔒 Security Best Practices Implemented
*   Removed vulnerable ID parameters (e.g., `studentId`, `instructorId`) from endpoints, relying on Token Claims.
*   Enforced Ownership Checks (e.g., Instructors can only download reports for courses they created).
*   Password Hashing via BCrypt.
